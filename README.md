# GitHub Security Scan Analysis

A practical security analysis project focused on Git/GitHub workflow, GitHub IP range discovery, network scanning, and security assessment using Nmap, Masscan, and Nikto.

## Security Scope

This project focuses on authorized security assessment and analysis of GitHub-related network ranges using Nmap, Masscan, Nikto, and structured reporting.

All scanning activities should be performed only on systems and resources that you own or are explicitly authorized to test.
